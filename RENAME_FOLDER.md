# Rename local folder to `EARLY`

The project is named **EARLY** (npm package `early`, GitHub repo `EARLY`).

If this folder is still `Early Assisted Reading`, rename it after closing Cursor:

```powershell
cd C:\
Rename-Item -LiteralPath "Early Assisted Reading" -NewName "EARLY"
```

Then reopen the project: **File → Open Folder → `C:\EARLY`**

Delete this file after renaming if you like.
