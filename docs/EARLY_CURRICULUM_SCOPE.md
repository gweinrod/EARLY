# EARLY curriculum scope and sequence

Early Assisted Reading and Literacy for Youth — pedagogical framework for the app.

## Pedagogical foundation

EARLY uses structured **see** (written word, phoneme symbol), **hear** (model pronunciation, student playback), and **manipulate** (phoneme substitution, word building) practice, shaped by classroom experience.

Core insight: consonant **letter names** contain their phoneme ("bee" has /b/, "eff" has /f/), giving students a self-teaching hook from day one. Vowel **letter names** are the long sound, but vowels say their **short** sound when alone in a word. That principle, fully internalized, is the foundation for later units.

## Mastery threshold

| Parameter | Value | Rationale |
|-----------|-------|-----------|
| Accuracy threshold | 90% | Tight enough to prevent premature advancement |
| Consecutive sessions | 2 | One good session could be luck; two is a pattern |
| Words per phoneme | 2–3 per session | Enough data to attribute errors to the target phoneme |
| Session scope (Unit 1) | All 26 phonemes | No gaps in the Foundation Block |
| Word type (Unit 1) | CVC only | Protects open/closed syllable rule for Unit 4 |

Unit 3 (irregular sight words) uses whole-word recognition via speech-to-text rather than phoneme analysis. The 90/2 rule still applies but is measured on whole-word accuracy.

## Unit 1 — Alphabet and shorts (foundation block)

Stages 1, 2, and 3 are learned together. A student does not advance to Unit 2 until all three stages are mastered. All content is assessed every session.

| Stage | Content | Key insight |
|-------|---------|-------------|
| 1 — Alphabet and letter names | All 26 letter names | Consonant names contain the phoneme. Vowel names are the long sound. |
| 2 — Consonant sounds | All 21 consonants | Letter name is the anchor: "bee" gives /b/, "eff" gives /f/. |
| 3 — Short vowels | /æ/ /?/ /?/ /?/ /?/ in CVC words | A vowel alone in a word says its short sound (closed syllable, unnamed at this stage). |

Session structure:

- At least 26 items per session (21 consonants + 5 short vowels when in stage 3)
- 2–3 CVC words per target phoneme when applicable
- Randomized order each session
- No CV-only words in Unit 1 (protects syllable rules for Unit 4)
- Interleaved consonants and vowels

**Exit criterion:** 90% accuracy across 2 consecutive sessions on all 26 phonemes.
